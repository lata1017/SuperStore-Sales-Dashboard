🛒 Super Store Sales Dashboard (Power BI)
📊 Project Overview

This project presents a Sales Analysis Dashboard built using Microsoft Power BI to analyze the performance of a retail Super Store. The dashboard provides insights into sales, profit, orders, customer segments, shipping methods, and regional performance.

The goal of this project is to help businesses understand their sales performance and make data-driven decisions.

📂 Dataset

The dataset contains information about:

Order Date

Ship Date

Customer Segment

Region and State

Product Category & Sub-Category

Sales and Profit

Payment Mode

Shipping Mode
